# Ommi Food

**من مطبخ أمهاتنا... إلى قلب بيتك**

الموقع الفعلي: https://ommi-food.pages.dev/

واجهة HTML/CSS/JavaScript مع Supabase للجلسات والطلبات والمطابخ. المرجع الحالي للمنتج هو [PRODUCT_DECISIONS.md](PRODUCT_DECISIONS.md)، وتقسيم الكود في [ARCHITECTURE.md](ARCHITECTURE.md). لا توجد مصفوفة مطابخ تجريبية تُعدّل يدويًا في الواجهة.

## التطوير والتحقق

يتطلب Node.js 22 أو أحدث وPython 3.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run build
```

البناء يشغّل الاختبارات قبل إنشاء `dist/`. فشل الاختبارات أو تكرار تعريف وظيفة يمنع تجهيز نسخة النشر. يستخدم البناء قائمة ملفات عامة محددة ويغيّر نسخة روابط JavaScript وCSS حسب محتواها تلقائيًا. لا ينشر ملفات SQL أو الاختبارات أو إعدادات التطوير.

`index.html` و`admin.html` هما مرجع ترتيب السكربتات. الاختبارات تقرأ القائمة نفسها، ولا تحتفظ بترتيب مختلف خاص بها. يجري GitHub Actions البناء نفسه عند كل push أو pull request.

## النشر

انشر محتويات `dist/` بعد اجتياز البناء على المشروع القائم. لا تنشئ موقعًا بديلًا لمجرد نجاح اختبار محلي أو معاينة. بعد النشر تحقّق من https://ommi-food.pages.dev/ ومن وصول نسخ السكربتات الجديدة وسلامة المسار الفعلي.

نجاح الاختبارات الآلية لا يساوي اكتمال تجربة هاتف حقيقية بحسابين. تفاصيل التغطية والاختبارات المعزولة لقاعدة البيانات في [tests/README.md](tests/README.md).

## قاعدة البيانات

التعديلات الجديدة تكون migrations في `supabase/migrations/`. ملفات SQL التاريخية في `db/` تفسّر تطور المشروع، ولا يُعاد تطبيقها فوق القاعدة الحالية دون مراجعة. اختبارات قاعدة البيانات تنفّذ ملفاتها كاملة داخل `BEGIN` / `ROLLBACK`، فلا تحتفظ بمطابخ أو طلبات الاختبار.
